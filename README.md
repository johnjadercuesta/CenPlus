# CenPlus - Sistema de Gestión de Censos y Ciudadanos

CenPlus es una aplicación moderna para la gestión de censos, permitiendo la visualización de datos demográficos a través de mapas de calor, KPIs y formularios detallados para la recopilación de información ciudadana.

## Características

- **Gestión de Ciudadanos**: Formulario completo para registrar información personal y de ubicación.
- **Visualización de Datos**: Dashboard con indicadores clave (KPIs) sobre el estado de los censos.
- **Mapa de Calor**: Visualización interactiva de la distribución de ciudadanos por sectores.
- **Gestión de Sectores**: Panel administrativo para organizar barrios y sectores.

## Tecnologías Utilizadas

- **Frontend**: Next.js, React, Tailwind CSS, Lucide React.
- **Base de Datos**: SQLite (mediante Better-SQLite3).
- **Estilización**: Vanilla CSS y Tailwind CSS para un diseño premium y responsive.

## Configuración y Ejecución

1.  **Instalar dependencias**:
    ```bash
    npm install
    ```
2.  **Iniciar el servidor de desarrollo**:
    ```bash
    npm run dev
    ```
3.  **Acceder a la aplicación**: Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
